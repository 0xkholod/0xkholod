## `whoami`

I am a systems administrator moving deeper into offensive security. My work is grounded in the realities of operating Windows and Linux infrastructure, Active Directory, access control, web services, and incident response.

I approach security by first understanding how a system is built, where trust is placed, and what must keep working when that trust breaks. I hold the **HTB Certified Penetration Testing Specialist** certification and I am currently pursuing the **HTB CWES**.
